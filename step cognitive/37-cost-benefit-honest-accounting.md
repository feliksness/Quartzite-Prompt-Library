# Cost-Benefit Honest Accounting

*Lists real costs and benefits without quietly favoring one side.*

```
Do an honest cost-benefit accounting:

1. List every real benefit, including ones the proposer of this option would not think to mention.
2. List every real cost, including soft costs (time, attention, opportunity, risk), not just money.
3. Check you gave both lists equal effort — if one side is thin, dig harder before continuing.
4. State the net judgment and what would have to change to flip it.
```
