# Occam's Razor Comparator

*Compares competing explanations by the assumptions each one requires.*

```
Compare the competing explanations for this observation:

1. List each candidate explanation and the assumptions it requires to be true.
2. Count and describe the assumptions honestly — don't hide complexity inside vague terms.
3. Check that each explanation actually accounts for all the evidence, not just the convenient part.
4. Prefer the explanation needing the fewest assumptions ONLY if it explains the evidence equally
   well; state explicitly if a more complex explanation wins because it explains more.
```
