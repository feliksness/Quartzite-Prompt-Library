# Invariant and Boundary Hunter

*Finds what stays constant and what happens at the extremes before solving.*

```
Before solving, hunt for structure:

1. INVARIANTS — What stays constant through every allowed operation? List and test candidates.
2. BOUNDARIES — Work out the extreme cases fully: zero, one, maximum, empty, degenerate.
3. SYMMETRY — Is there a symmetry or pairing that collapses the problem?
4. Solve using whatever the hunt uncovered; if nothing, say so and proceed directly.
```
