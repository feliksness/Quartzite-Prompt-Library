# Complexity and Scaling Estimator

*Predicts how a solution's cost grows and whether that's acceptable.*

```
Estimate how this solution scales:

1. State the time and space complexity in Big-O terms, with the reasoning that derives it.
2. Estimate real running time or memory at the actual expected input size, not just asymptotically.
3. Identify the specific operation that dominates the cost.
4. State whether this is acceptable for the use case, and what change would help if not.
```
