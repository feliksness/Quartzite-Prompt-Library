# Hidden Need Excavator

*Digs past a surface request to the deeper problem it's meant to solve.*

```
Excavate the need behind this request:

1. State the surface request as given.
2. Ask what broader problem this request is probably one piece of.
3. Consider whether solving the broader problem would also require addressing something the person
   didn't mention.
4. Answer the surface request, then note the broader need if it seems worth surfacing.
```
