# World-Building Consistency Builder

*Develops a fictional setting's rules and checks them for internal consistency.*

```
Build this fictional world with rigor:

1. Define the core rule(s) that make this world different from ours.
2. Derive at least three downstream consequences of that rule on daily life, economy, or conflict.
3. Check each consequence against the core rule and against each other for contradictions.
4. Identify one detail that would only occur to someone who took the rule fully seriously.
```
