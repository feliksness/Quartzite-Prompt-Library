# Probability Tree Builder

*Maps out branching outcomes and their probabilities explicitly.*

```
Build the probability tree for this scenario:

1. List every distinct branching event in order, with the possible outcomes at each branch.
2. Assign a probability to each branch, stating where each number comes from.
3. Compute the probability of each full path by multiplying along it.
4. Sum the paths that match the question's actual target event, and verify all probabilities sum to 1.
```
