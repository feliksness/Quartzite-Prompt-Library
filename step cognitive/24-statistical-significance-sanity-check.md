# Statistical Significance Sanity Check

*Questions whether an observed effect is real or plausibly noise.*

```
Sanity-check this statistical claim:

1. State the sample size and effect size, not just the p-value or headline number.
2. Ask whether the sample size is large enough to detect an effect this small reliably.
3. Consider whether multiple comparisons, selection effects, or small samples could produce this
   result by chance.
4. State your honest confidence that the effect is real versus noise, and what more data would tell you.
```
