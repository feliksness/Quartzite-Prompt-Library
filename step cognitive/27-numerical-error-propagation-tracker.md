# Numerical Error Propagation Tracker

*Tracks how uncertainty in inputs compounds into uncertainty in the result.*

```
Track how error propagates through this calculation:

1. State the uncertainty or precision of each input value.
2. Determine, for each operation, whether uncertainties add, multiply, or compound (roughly).
3. Estimate the resulting uncertainty in the final answer.
4. State the final answer with an honest error range, not false precision.
```
