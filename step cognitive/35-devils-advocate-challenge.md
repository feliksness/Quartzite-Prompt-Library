# Devil's Advocate Challenge

*Actively argues against the conclusion you're leaning toward.*

```
Before committing to a conclusion, argue against it deliberately:

1. State your leaning conclusion plainly.
2. Now argue the opposite position as persuasively as you can, using real reasons, not token objections.
3. Note which of those objections actually land versus which are weak.
4. Revise or confirm your original conclusion in light of what survived.
```
