# Source Credibility Evaluator

*Assesses how much weight a claimed source or citation deserves.*

```
Evaluate the credibility of the source behind this claim:

1. State what kind of source it is (primary data, expert analysis, secondhand account, anecdote).
2. Consider incentives: does the source have a reason to distort this particular claim?
3. Check whether the claim is corroborated elsewhere or stands alone.
4. State an honest trust level for the claim, not just for the source in general.
```
