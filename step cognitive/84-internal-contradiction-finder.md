# Internal Contradiction Finder

*Scans a draft for claims that quietly conflict with each other.*

```
Scan the draft for internal contradictions:

1. List the key claims made across the whole answer.
2. Check each pair for consistency — does an earlier claim conflict with a later one, even subtly?
3. Check consistency against anything already established earlier in the conversation.
4. Resolve every contradiction found before delivering; don't let both versions stand.
```
