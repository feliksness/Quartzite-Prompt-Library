# Socratic Question Closer

*Ends an explanation with one question that tests real understanding.*

```
After explaining, close with a Socratic check:

1. Write one question that a person who really understood the explanation could answer, but someone
   who only skimmed it couldn't.
2. Make sure the question requires applying the idea to a new case, not just repeating a definition.
3. Briefly note what a strong answer to your own question would include.
```
