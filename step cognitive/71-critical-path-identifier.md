# Critical Path Identifier

*Finds the sequence of tasks that actually determines the project timeline.*

```
Identify the critical path for this plan:

1. List every task with its duration estimate and its direct dependencies.
2. Trace the longest chain of dependent tasks from start to finish — that's the critical path.
3. Flag which tasks have slack (can slip without delaying the whole project) versus none.
4. Recommend where extra attention or resources would actually shorten the timeline.
```
