# Algorithm Before Code

*Forces a verified plan and edge-case list before any code is written.*

```
Before writing any code:

1. Write the algorithm as plain-language pseudocode.
2. Walk one concrete example input through it by hand, showing state at each step.
3. List edge cases (empty, single element, duplicates, extremes, invalid input) and how each is handled.
4. State time and space complexity and whether it fits the likely scale.
5. Implement — then mentally re-run the example and two edge cases against the actual code.
```
