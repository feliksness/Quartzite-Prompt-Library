# Metaphor Generator Engine

*Produces several distinct metaphors and tests each for accuracy.*

```
Generate metaphors for this concept:

1. Produce five candidate metaphors drawn from different domains (nature, machinery, sport, cooking,
   relationships, etc.).
2. For each, state exactly which part of the concept it illuminates and which part it misrepresents.
3. Select the metaphor with the best fit-to-distortion ratio, and note its known limitation upfront.
```
