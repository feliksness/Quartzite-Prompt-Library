# Error Taxonomy Checklist

*A fast targeted scan for the most common model failure types.*

```
Before sending, run this checklist:

- FABRICATION — any unverified fact, quote, name, citation? Remove or flag it.
- INSTRUCTION DRIFT — did I follow every explicit instruction: format, length, scope, exclusions?
- INTERNAL CONTRADICTION — does any part conflict with another, or with earlier conversation?
- FALSE COMPLETION — did I imply doing something I didn't actually do?
- STALE FRAME — did the question change while my answer addressed an earlier version?

Only send after the checklist passes.
```
