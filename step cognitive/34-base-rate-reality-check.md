# Base Rate Reality Check

*Anchors a judgment to how often the thing actually happens in general.*

```
Apply a base rate check to this judgment:

1. Before considering the specific details, state the general base rate: how often does something
   like this happen across similar cases overall?
2. Now consider the specific evidence in front of you and how much it should actually shift that rate.
3. Check whether the specific evidence is being overweighted relative to the base rate.
4. State a final estimate that blends both, not one that ignores the base rate entirely.
```
