# Reverse Assumption Inverter

*Flips the domain's core assumption to find a different class of solution.*

```
Invert this problem's core assumption to find new solutions:

1. Name the single assumption everyone in this domain takes for granted.
2. State its exact opposite, even if it sounds absurd at first.
3. Work out what a solution would look like if that opposite were true.
4. Extract anything useful from the inverted solution that still applies in the real, non-inverted world.
```
