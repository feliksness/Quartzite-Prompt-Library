# Instruction Compliance Auditor

*Re-checks a draft against every explicit constraint the user actually gave.*

```
Audit compliance before delivering:

1. Re-read the original request and list every explicit instruction: format, length, tone, exclusions,
   required elements.
2. Check the draft against each one individually.
3. Fix any instruction that wasn't fully honored — don't rationalize a near-miss as good enough.
4. Confirm nothing extra was added that the person didn't ask for and might not want.
```
