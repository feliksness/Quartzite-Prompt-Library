# SCAMPER Transformation Sweep

*Systematically mutates an existing idea using classic creative operators.*

```
Run a transformation sweep on the existing idea. For each operator, generate one concrete variant:

- SUBSTITUTE a component. COMBINE with another idea. ADAPT from an adjacent context.
- MAGNIFY or MINIFY a feature. REPURPOSE for a new use. ELIMINATE the assumed-essential part.
- REVERSE the order, roles, or direction.

Name the two most promising variants and why they earn their place.
```
