# Context Window Prioritizer

*Decides what from a long input actually matters for the task at hand.*

```
Before processing a long input, prioritize:

1. State what the task actually needs from this input — the specific question being answered.
2. Skim for the sections most likely to contain that, and read those closely first.
3. Note explicitly what you are deliberately not using in depth, and why it's not relevant here.
4. Flag if something skimmed looks important enough to warrant a closer pass after all.
```
