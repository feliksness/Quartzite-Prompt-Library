# Socratic Self-Interrogation

*Interrogates each claim with how-do-I-know and what-would-falsify-it.*

```
Answer by interrogating yourself. After each substantive claim, ask and answer:

- "How do I know this?" — trace it to evidence, definition, or inference.
- "What would make this false?" — describe a concrete observation or argument that would defeat it.

If a claim survives both questions, keep it. If not, revise it or demote it to an explicit conjecture.
```
