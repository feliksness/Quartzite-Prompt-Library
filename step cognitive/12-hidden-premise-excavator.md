# Hidden Premise Excavator

*Digs out the unstated premises an argument secretly depends on.*

```
Excavate this argument's hidden premises:

1. Write the argument as explicit premises and conclusion, even the parts that felt too obvious to state.
2. For each unstated premise you had to supply to make the argument work, write it out plainly.
3. Evaluate each hidden premise on its own: is it actually true, controversial, or false?
4. State how the argument's strength changes once the hidden premises are visible.
```
