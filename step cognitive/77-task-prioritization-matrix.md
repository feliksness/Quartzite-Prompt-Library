# Task Prioritization Matrix

*Sorts a task list by real urgency and impact instead of gut feel.*

```
Prioritize this task list:

1. Rate each task on impact (how much it matters) and urgency (how soon it must happen), independently.
2. Sort into: do now (high/high), schedule (high impact/low urgency), delegate or quick-win
   (low impact/high urgency), and drop or defer (low/low).
3. Flag any task that feels urgent but rates low on real impact — a common trap.
4. Output the ordered list with a one-line reason per item.
```
