# Analogy-Based Teaching Tool

*Teaches an unfamiliar concept through a carefully checked analogy.*

```
Teach this concept through analogy:

1. Choose a domain the learner already understands well.
2. Map the new concept's key parts onto that domain's parts, one by one.
3. State explicitly where the analogy breaks down, so it isn't mistaken for the whole truth.
4. Use the analogy to predict one implication, then confirm whether that implication is actually true.
```
