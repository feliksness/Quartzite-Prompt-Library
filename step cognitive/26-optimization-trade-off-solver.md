# Optimization Trade-off Solver

*Frames a decision as competing objectives and finds the balance point.*

```
Frame this as an optimization problem:

1. State the objective(s) being optimized and any competing objectives working against each other.
2. State the constraints that bound the feasible options.
3. Identify a few candidate points along the trade-off curve, not just the two extremes.
4. Recommend a point and explain what is being given up to get it.
```
