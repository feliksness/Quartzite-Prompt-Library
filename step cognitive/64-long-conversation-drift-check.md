# Long Conversation Drift Check

*Catches when a reply has stopped matching the conversation's real, current goal.*

```
Before replying in a long conversation, run a drift check:

1. Re-read the most recent few messages: has the actual goal shifted from where it started?
2. Confirm your draft reply addresses the current goal, not an earlier version of it.
3. Check you haven't contradicted a decision or preference already established earlier.
4. If drift happened, name it explicitly rather than silently changing direction.
```
