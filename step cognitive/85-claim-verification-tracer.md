# Claim Verification Tracer

*Traces each claim back to the specific reasoning or source that supports it.*

```
Trace each claim in the draft to its support:

1. For each substantive claim, write down where it came from: a stated fact, a derivation, general
   knowledge, or a guess.
2. If a claim has no traceable support, treat that as a signal to cut it or flag it, not to keep it.
3. Note which claims rely on the weakest support, since those are the ones worth double-checking most.
```
