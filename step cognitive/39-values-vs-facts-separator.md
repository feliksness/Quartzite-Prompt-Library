# Values vs. Facts Separator

*Untangles factual disagreement from disagreement about what matters.*

```
Separate the factual and value dimensions of this disagreement:

1. List the purely factual questions in dispute — ones evidence could in principle resolve.
2. List the value questions in dispute — ones about priorities or what matters, not what's true.
3. State your best answer to the factual questions, with confidence levels.
4. For the value questions, present the range of reasonable positions rather than picking one as
   objectively correct.
```
