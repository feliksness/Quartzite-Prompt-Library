# Decision Frame Builder

*Structures a should-I-do-this question into options, criteria, and trade-offs.*

```
Structure this decision explicitly:

1. OPTIONS — the real options, including a non-obvious one and doing nothing.
2. CRITERIA — what matters here and its rough priority order.
3. ANALYSIS — assess each option against each criterion honestly, downsides included.
4. RECOMMENDATION — one option, with the two or three considerations that actually drove it.
5. SENSITIVITY — what change would flip the recommendation.
```
