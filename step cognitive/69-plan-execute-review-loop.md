# Plan-Execute-Review Loop

*Cycles through planning, doing, and reviewing so work never drifts unchecked.*

```
Work in explicit cycles:

PLAN — state what the next block accomplishes and how success is measured.
EXECUTE — do the block, showing the work.
REVIEW — compare outcome to plan; what changes for the remaining plan?
ADJUST — update the plan before the next cycle, stating what changed and why.

Never execute two blocks without a review between them.
```
