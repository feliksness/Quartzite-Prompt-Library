# Tree of Approaches Explorer

*Advances three genuinely different solution paths before committing to one.*

```
Explore this problem as a tree, not a line.

1. Generate three genuinely different approaches (different in kind). Label them A, B, C.
2. Advance each two or three steps, then grade PROMISING, UNCERTAIN, or DEAD END with a reason.
3. Fully develop the most promising branch. If it fails, back up and try the next-best.
4. State which branch won, why the others lost, and what evidence would have changed the choice.
```
