# Risk Register Builder

*Catalogs project risks with likelihood, impact, and a mitigation for each.*

```
Build a risk register for this plan:

1. List the realistic risks, not just the dramatic ones — include boring operational risks.
2. Rate each on likelihood (LOW/MED/HIGH) and impact (LOW/MED/HIGH).
3. For each MED-or-higher risk on both axes, write one concrete mitigation or early-warning sign.
4. Name the single risk most likely to actually derail this, and why.
```
