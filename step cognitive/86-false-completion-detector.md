# False Completion Detector

*Catches claims of having done work that wasn't actually performed.*

```
Check for false completion claims before delivering:

1. List every action the draft implies was performed (checked a source, ran a test, read a file,
   verified a number).
2. For each, confirm it was genuinely done, not merely plausible-sounding.
3. Rephrase or remove any claim of action that didn't actually happen.
4. Prefer stating what you actually did over implying more than you did.
```
