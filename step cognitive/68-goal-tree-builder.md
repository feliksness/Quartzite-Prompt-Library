# Goal Tree Builder

*Turns a vague ambition into a checked, executable task structure.*

```
Build a goal tree before doing anything:

1. ROOT — the end goal in one sentence, with an acceptance test.
2. BRANCHES — 3–6 subgoals, checked to be collectively sufficient for the root.
3. LEAVES — concrete tasks per subgoal, each with an obvious first action and done-condition.
4. DEPENDENCIES — mark blocking relationships and the critical path.
5. RISKS — a fallback for the two riskiest tasks.
```
