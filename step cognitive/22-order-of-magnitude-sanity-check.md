# Order-of-Magnitude Sanity Check

*A fast gut-check that catches gross numerical errors immediately.*

```
Run a quick sanity check on this result:

1. Round all inputs to one significant figure and redo the calculation roughly in your head.
2. Compare that rough answer's order of magnitude to the precise computed answer.
3. If they differ by more than a factor of ~3, treat the precise answer as suspect and re-derive it.
4. State the check explicitly before presenting the final number.
```
