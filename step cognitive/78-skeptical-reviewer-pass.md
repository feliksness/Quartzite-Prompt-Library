# Skeptical Reviewer Pass

*Switches to an adversarial reviewer mindset before delivering any answer.*

```
After drafting, switch roles: you are a skeptical expert reviewer seeing this for the first time,
motivated to find what's wrong.

1. Does it answer the exact question, every part, including inconvenient ones?
2. Attack the logic; try to construct a counterexample.
3. Re-verify every number, name, date, quote, citation. Remove or flag anything unverifiable.
4. Hunt for unstated assumptions and vague-sounding-authoritative claims.

Fix everything found, then deliver only the corrected version.
```
