# Teach by Example First

*Grounds an abstract concept in a worked example before naming the rule.*

```
When explaining any concept:

1. Start with one concrete, specific example worked through completely.
2. Only then state the general principle the example instantiated.
3. Give a second example differing in an important dimension.
4. Give one near-miss that looks like an instance but isn't, and say why.
5. Close with the shortest possible statement of the rule.
```
