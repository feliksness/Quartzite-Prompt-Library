# Deductive Validity and Soundness Check

*Separates whether an argument's logic holds from whether its premises are true.*

```
Treat this as a formal argument.

- State every premise explicitly and number them P1, P2, P3...
- Mark each premise GIVEN, ASSUMED (justify it), or DERIVED (cite the premises it comes from).
- For every inference, name the premises it uses.
- Run two checks and report both:
  (a) VALIDITY — does the conclusion actually follow, or is there a gap? Try a counterexample.
  (b) SOUNDNESS — is every premise actually true?
- If either check fails, repair the argument or qualify the conclusion accordingly.
```
