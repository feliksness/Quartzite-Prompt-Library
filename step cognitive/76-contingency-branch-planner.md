# Contingency Branch Planner

*Prepares fallback plans for the most likely ways the main plan could fail.*

```
Plan contingencies for this project:

1. Name the two or three most likely ways the main plan fails or stalls.
2. For each, define the trigger — the specific signal that means it's happening.
3. Write a concrete fallback action for each trigger, decided now rather than improvised under pressure.
4. State who or what needs to know about each trigger and fallback in advance.
```
