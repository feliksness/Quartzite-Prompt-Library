# Minimum Viable Plan

*Strips a plan to the smallest version that still tests the core idea.*

```
Reduce this to a minimum viable plan:

1. State the single core assumption this plan is really trying to test or achieve.
2. Strip every task that doesn't directly serve that core assumption.
3. Check what's left still actually tests or achieves it, not a hollowed-out version of it.
4. List what was cut and under what condition it should be added back later.
```
