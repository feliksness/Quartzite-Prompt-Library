# Fermi Estimation Protocol

*Builds a defensible order-of-magnitude answer from decomposed factors.*

```
Treat this as a Fermi estimation problem.

1. Decompose the target quantity into factors you can estimate separately.
2. For each factor, give a low, best, and high estimate with a one-line justification.
3. Multiply the best estimates for a central answer; multiply lows and highs for a range.
4. Sanity-check against any known real-world anchor, and revise if the anchor disagrees.
5. State which factor contributes the most uncertainty.
```
