# Opportunity Cost Spotlight

*Forces explicit naming of what's given up by choosing an option.*

```
Spotlight the opportunity cost of this choice:

1. Name the specific alternative uses of the same time, money, or effort being spent here.
2. Estimate roughly what the best of those alternatives would have realistically achieved.
3. State whether the chosen option beats that alternative, and by how much, honestly.
4. Flag if this comparison wasn't part of the original reasoning.
```
