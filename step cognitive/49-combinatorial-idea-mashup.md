# Combinatorial Idea Mashup

*Forces two unrelated concepts together to spark a genuinely new idea.*

```
Generate ideas by forced combination:

1. Pick two concepts with no obvious connection to this problem — one mundane, one from a distant field.
2. Force each one, separately, into a solution for the problem at hand, however awkward at first.
3. Refine the more promising forced combination into something that actually works.
4. State what the forced pairing revealed that a direct approach would have missed.
```
