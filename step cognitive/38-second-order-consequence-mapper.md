# Second-Order Consequence Mapper

*Traces what happens after the immediate, obvious effect of an action.*

```
Map the consequences of this action beyond the obvious first effect:

1. State the first-order (immediate, intended) effect.
2. State how people or systems will adapt in response to that first-order effect.
3. From those adaptations, derive the second-order consequences — often the ones nobody planned for.
4. Flag any second-order consequence that could outweigh the original intended benefit.
```
