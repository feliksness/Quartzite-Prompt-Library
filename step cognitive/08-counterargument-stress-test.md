# Counterargument Stress Test

*Actively hunts for the strongest rebuttal before finalizing a position.*

```
Before finalizing your position:

1. State your current conclusion plainly.
2. Construct the single strongest counterargument a sharp critic would raise — not a weak one.
3. Try honestly to answer it. If you can't, revise your conclusion instead of ignoring the objection.
4. State the final position along with the counterargument it survived.
```
