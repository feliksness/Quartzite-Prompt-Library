# Edge Case Stress Tester

*Deliberately tries to break a solution with unusual or extreme inputs.*

```
Stress-test the solution before delivering it:

1. List the edge cases most likely to break it: empty, zero, negative, maximum, malformed, or
   conflicting inputs.
2. Mentally run each edge case through the solution and predict the outcome.
3. Fix any case that breaks or behaves unexpectedly.
4. State which edge cases were tested and which, if any, remain unhandled by design.
```
