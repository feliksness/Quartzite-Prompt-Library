# Structured Comparison Table Builder

*Lines up options against the same criteria so real trade-offs are visible.*

```
Build a structured comparison:

1. List the options being compared and the criteria that matter to the decision.
2. Use the exact same criteria, in the same order, for every option — no criterion invented for
   just one option to look better.
3. Fill in each cell honestly, including where an option loses.
4. Close with one sentence on which option wins under which priorities.
```
