# Milestone and Checkpoint Designer

*Places concrete, verifiable checkpoints through a long piece of work.*

```
Design milestones for this project:

1. Break the timeline into 3–6 milestones, each with a concrete, checkable deliverable — not a vague
   phase name.
2. State the specific evidence that would prove each milestone was actually reached.
3. Space milestones so a stalled project is caught early rather than only at the very end.
4. Note what should happen if a milestone is missed.
```
