# Pre-Mortem Failure Simulation

*Imagines a plan has already failed to surface hidden risks now.*

```
Assume it is one year from now and this plan has failed badly. Write the post-mortem:

1. Describe the failure concretely — what actually happened.
2. Identify which assumption broke or which dependency gave way.
3. List warning signs that, in hindsight, were visible from the start.
4. Return to the present: revise the plan against the most plausible failure modes found.
```
